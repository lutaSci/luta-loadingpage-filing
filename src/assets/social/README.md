# Social brand icons

Source: [Simple Icons 16.30.0](https://github.com/simple-icons/simple-icons/releases/tag/16.30.0), npm archive `simple-icons-16.30.0.tgz`.
Only the four SVGs used by the footer are vendored. Geometry is unchanged; the root fill is set to each platform color. No third-party icon request occurs in a visitor browser. Icons are decorative beside explicit platform names.

The upstream CC0 license and trademark disclaimer are retained here. Brand marks identify destinations and do not imply endorsement.
